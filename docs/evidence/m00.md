## Blockers encountered and resolved

1. `rdkafka` requires `cmake`/`pkg-config` (neither installed). Resolved
   by switching to `rskafka` (pure Rust) — see ADR 0001.
2. Redpanda image `v24.2.7`'s `rpk redpanda start` does not accept
   `--set key=value` (confirmed via `--help`); the original
   `docker-compose.yml` command crash-looped with
   `Argument parse error: unrecognised option '--set=...'`. Resolved by
   dropping the flag from the start command and disabling
   `auto_create_topics_enabled` post-startup via `rpk cluster config set`
   in `make up`.
3. Host port `5432` was already bound by an unrelated project's Postgres
   container on this machine. Resolved by defaulting `POSTGRES_PORT` to
   `55432` in `.env.example` (container-internal port is unaffected).

No other blockers. Infrastructure left running after this evidence run
(`docker compose ps` above reflects the state at commit time) since M01
needs Postgres immediately.
