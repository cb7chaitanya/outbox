The chaos run stopped and restarted Redpanda while an accepted order's outbox
was pending, stopped and restarted Postgres while checking 503/200 readiness,
killed and restarted the orders worker, injected a malformed inventory record,
and proved valid following work still completed. Volumes were retained and no
manual database correction was used.

Fault controls remain disabled by default, require a token when enabled, and
all four service configurations reject enablement in `production`.

Prometheus alert rules cover old outbox rows, growing consumer lag, new DLQ
records, and stuck compensation. Metrics use fixed result labels only; IDs,
SKUs, keys, payloads, and raw errors are not labels. Operational procedures
are in `docs/runbook.md`.
